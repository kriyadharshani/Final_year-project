Mobile Attendance System with Facial Recognition
Project Description

The Mobile Attendance System with Facial Recognition is an Android-based application developed to provide a secure, efficient, and automated method of attendance management. The system leverages facial recognition technology and GPS location tracking to ensure accurate attendance recording while minimizing manual intervention.

The application is designed with role-based access and supports Students, Lecturers, and Administrators, each with specific permissions and functionalities. In addition, the system enables structured attendance reporting and direct communication via email.

Key Objectives

Automate attendance using facial recognition technology

Ensure attendance authenticity through GPS, date, and time capture

Provide centralized attendance management for academic institutions

Enable monitoring, reporting, and communication through a single platform
